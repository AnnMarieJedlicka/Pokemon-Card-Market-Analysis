## Project Overview

This project analyzes Pokémon card market data to identify pricing trends, high-value inventory opportunities, and product categories that can support business and marketing decisions for Pokémon card retailers.

## Business Objective

The objective of this project was to determine:

- Which Pokémon have the highest market value
- Which rarity classes command premium prices
- Which sets perform best in the secondary market
- How data can support inventory and promotional decisions

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Excel

## Dataset

- 251 Pokémon card listings
- 32 cleaned analytical variables
- Market pricing, rarity, and set-level information

## Methodology

### Data Cleaning

- Removed empty and unnecessary columns
- Validated pricing information
- Standardized data for analysis
- Organized card attributes into a usable analytical dataset

### Data Analysis

- Analyzed average market value by Pokémon
- Evaluated pricing differences by rarity class
- Compared set-level performance
- Examined market value distribution

## Key Findings

### Top Pokémon by Average Market Value

Images/top_pokemon_value.png

**Finding:** Charizard demonstrated the highest average market value, significantly outperforming most other Pokémon within the dataset.

### Average Price by Rarity

![Rarityarity_values.png

### Top Sets by Average Value

Images/top_sets.png

### Price Distribution

Images/price_distribution.png

**Finding:** Market value was concentrated among a relatively small number of high-value cards.

## Business Recommendations

Based on the analysis:

- Prioritize inventory acquisition for high-performing Pokémon such as Charizard.
- Focus marketing campaigns on premium rarity cards.
- Promote top-performing sets through social media content.
- Use market pricing trends to guide purchasing decisions.
- Highlight high-value cards during livestreams and product promotions.
